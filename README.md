**Rahim's Tools**
A simple web-based school management utility designed for everyday school tasks.
Features
📋 Attendance Management
🧾 Fee Receipt
💰 Fee Reminder
📱 WhatsApp / SMS Support
🔐 Password Protected Fee Tools
✨ Modern Neon UI
📱 Mobile Friendly
How to Use
Open the website and select the required tool:
Attendance — Manage daily student attendance.
Fee Receipt — Generate fee receipts.
Fee Reminder — Prepare fee reminder messages for parents.
Fee Tools Password
The Fee Receipt and Fee Reminder sections are password protected.

Installation
No installation is required.
Simply open the HTML file in a modern web browser.
GitHub Pages
This project can be hosted directly using GitHub Pages.
If the main file is named:
index.html
the website will open directly from the GitHub Pages link.
If the file is named:
attendance.html
you will need to add /attendance.html at the end of the website address.
